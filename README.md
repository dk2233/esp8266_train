# esp8266_train
Repo to play with ESP8266 



espnow_relays - is a receiver to communicate with espnow_remote from 
https://github.com/dk2233/esp32_sandbox/tree/main/espnow_remote

I use version of esp8266 - NodeMCU v3 - but it can be any available
pin GPIO_NUM_4 to first relay 
pin GPIO_NUM_5 to second relay (both controll almost immedietly) - it is used for a water pump controll
